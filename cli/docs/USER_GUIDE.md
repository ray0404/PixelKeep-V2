# PixelKeep JSON Snapshot CLI Bridge: User Guide

## 📖 Introduction
The **PixelKeep JSON Snapshot CLI Bridge** is a sophisticated utility designed to connect the local-first, secure environment of the PixelKeep PWA with advanced terminal-based workflows. It allows users to interact with their encrypted backups (`pixel-keep-backup.json`) directly from the command line, enabling powerful automation, data analysis, and cross-tool integration.

## 🏗️ Technical Architecture
The bridge acts as a translation layer between two distinct environments:
1.  **The PWA Layer**: A web-based environment using IndexDB (Dexie.js) for storage and CryptoJS for AES-256 client-side encryption.
2.  **The Terminal Layer**: A Python-based environment designed for high-speed parsing, hierarchical reconstruction, and integration with Unix-style tools and AI protocols (MCP).

### The "Bridge" Mechanism
The core of this tool is the `PixelKeepBridge` class in `pixelkeep.py`. It performs three critical operations:
-   **Security Parity**: Implements a CryptoJS-compatible decryption engine using `pycryptodome`, ensuring that the same password used in the PWA works seamlessly in the terminal.
-   **Graph Reconstruction**: Resolves the flat `fs_nodes` array from the backup into a complex parent-child tree structure.
-   **Format Translation**: Maps PixelKeep's internal JSON schema to standard Markdown and the `jref` snapshot format.

## 🛠️ Command Reference

### 1. `inspect`
**Usage**: `python pixelkeep.py inspect <backup.json>`
Provides a high-level summary of the backup contents without requiring a password (metadata is not encrypted in the backup header).
- **Outputs**: Version, Export Timestamp, and counts for Notes, Tasks, and Nodes.

### 2. `tree`
**Usage**: `python pixelkeep.py tree <backup.json> [-p PASSWORD]`
Visualizes your entire PixelKeep hierarchy.
- **Hierarchical View**: Shows Folders, Notes, and Quests in their original nested structure.
- **Decryption**: If a password is provided, it resolves and displays the actual names of encrypted folders and notes.

### 3. `export`
**Usage**: `python pixelkeep.py export <backup.json> -p PASSWORD [-o OUTPUT_DIR]`
Transforms your encrypted database into a local Markdown knowledge base.
- **Markdown Conversion**: Each note is converted to a `.md` file with a YAML-like header for titles and tags.
- **Sanitization**: Filenames are automatically sanitized for filesystem compatibility.

### 4. `to-jref`
**Usage**: `python pixelkeep.py to-jref <backup.json> -p PASSWORD`
Generates a structured JSON snapshot compatible with the **JSON Reference (jref)** CLI.
- **Integration**: Allows you to pipe your notes directly into AI-agent workflows.
- **Example**: `python pixelkeep.py to-jref backup.json -p pass | jref inspect`

## 🔒 Security & Privacy
- **Client-Side Only**: Decryption happens entirely on your local machine. No data or passwords ever leave your terminal.
- **No Persistence**: The tool does not store your password. It must be provided via the `-p` flag or an environment variable for each session.
- **AES-256 Compatibility**: Uses the industry-standard AES-256-CBC algorithm with OpenSSL-style key derivation to match the PWA's security model.

## 🤖 AI & Tool Integration

### jref & MCP Integration
The most powerful use of this bridge is exposing your personal knowledge base to AI agents. By converting your backup to the `jref` format, you can:
1.  **Start an MCP Server**: `python pixelkeep.py to-jref backup.json -p pass > snap.json && jref serve snap.json`
2.  **Semantic Search**: Use `jref query` to find specific information across your entire history using natural language (if semantic indexing is enabled in `jref`).
3.  **Graph Analysis**: Trace connections between notes and tasks using `jref graph`.

## 📝 Example Workflow
1.  **Export** from the PixelKeep PWA (Settings -> Export Backup).
2.  **Verify** the backup in the terminal:
    ```bash
    python pixelkeep.py inspect pixel-keep-backup-2026-05-10.json
    ```
3.  **Browse** your structure:
    ```bash
    python pixelkeep.py tree pixel-keep-backup-2026-05-10.json -p my_secret_key
    ```
4.  **Analyze** with AI:
    ```bash
    python pixelkeep.py to-jref backup.json -p my_secret_key | jref query --path "notes/Research"
    ```
